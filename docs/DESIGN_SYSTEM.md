# VERROCCHIO visual system

- Background: chalk-white `#f2f0ea`, explicitly not cream.
- Ink: `#101218`.
- Oltremare: `#163fb8`; deep wet plaster: `#092e9b`.
- Signature edge: restrained gold `#c99b2b`.
- Display typography: high-contrast Cormorant Garamond.
- Operational typography: IBM Plex Mono; interface support: Inter.
- Containers: open editorial canvas, ruled ledgers, and one full-width wet-plaster strip. Avoid generic cards.
- Geometry: thin square rules, construction marks, no soft SaaS shadows or pill controls.
- Motion: only state transitions that explain drying, depletion, hold, or completion.
- Mobile: navigation becomes a horizontal workshop rail; OLTREMARE moves out of the persistent side rail.
